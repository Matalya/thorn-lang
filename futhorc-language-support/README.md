# Futhorc Language Support

Syntax highlighting and basic editor support for the Futhorc programming language.

## Features

- Syntax highlighting for `.futhorc` and `.þ` source files
- Futhorc keywords, types, built-ins, strings, numbers, and comments
- Basic bracket matching and automatic closing pairs

## Development

Press `F5` in VS Code to launch an Extension Development Host and test the extension.
